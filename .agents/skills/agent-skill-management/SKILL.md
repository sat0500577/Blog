# 에이전트·스킬 인사 관리

프로젝트 AGENTS.md의 관리 기준과 agents/hr-manager.md의 역할 지침을 적용한다.
블로그 콘텐츠 기획은 stock-editorial이 담당하며, 이 스킬은 팀 구성과 작업 역량을 관리한다.
인사팀은 블로그 실무팀과 독립된 지원 조직이다. 역할 정의와 스킬을 관리하는 권한을 실무팀에 대한 지휘·업무 배정 권한으로 해석하지 않는다.

1. 요청 목표와 산출물을 정하고 관련 역할 파일과 SKILL.md를 읽어 현재 구성을 확인한다.
2. 기존 조합으로 충분하면 해당 역할과 스킬을 추천한다. 부족한 기능이 있을 때 외부 후보 탐색이나 새 역할 설계를 진행한다.
3. GitHub 탐색 시 원문을 확인하고 아래 비교 항목을 제공한다.
   - 후보명과 저장소·스킬 경로 링크
   - 기능과 사용하기 좋은 상황
   - 인지도 근거와 확인일
   - 유지보수, 라이선스, 환경 호환성, 의존 도구와 비용
   - 기존 구성과의 중복 및 도입 판단
4. 역할 생성·수정 시 상위 보고 대상, 담당 범위, 입력, 수행 단계, 출력, 사용 스킬, 완료 기준을 정의한다.
5. 프롬프트 요청에는 역할과 목표, 사용자 입력 항목, 수행 단계, 결과 형식, 품질 기준을 갖춘 재사용 지시문을 작성한다.
6. 중복 제거 시 목적·실행 조건·입출력·수행 단계를 비교한다. 고유 기능을 보존하고 Git 복구 지점을 확보한 뒤 중복본과 관련 참조를 정리한다.
7. 변경 후 파일 참조와 역할·스킬 목록의 일치를 확인한다. 실행 기능을 도입했다면 가능한 범위에서 대표 작업으로 검증한다.
8. 회장님에게 결과, 선택 이유, 적용·검증 상태, 미해결 사항을 보고한다.

완료 기준: 요청한 관리 결과가 준비되고, 어떤 역할이 어떤 스킬을 사용하는지 명확하며, 추천·파일 작성·설치·실제 실행 상태가 구분된다.
