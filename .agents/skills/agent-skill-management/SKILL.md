# 인사팀 요청 분배와 결과 검수

프로젝트 AGENTS.md와 agents/hr-manager.md를 따른다. 탐색 실무는 skill-discovery, 제작 실무는 agent-building에 맡긴다.

1. 요청의 목표, 필요한 기능, 원하는 산출물과 기존 자산을 확인한다.
2. 탐색·추천은 스킬 탐색 담당, 제작·수정·프롬프트는 에이전트 제작 담당에게 배정한다. 실제 서브 에이전트 위임 시 각 역할 파일과 스킬을 읽도록 지시한다.
3. 업무 지시에는 목표, 이용 가능한 자료, 변경 가능한 파일, 산출물, 완료 기준을 포함한다. 동일 파일의 동시 수정을 피한다.
4. 두 작업이 필요한 경우 탐색과 제작의 의존성을 구분한다. 탐색 결과 없이 후보를 선정된 스킬로 간주하지 않는다. 제작 담당은 미리 입출력 설계를 준비할 수 있다.
5. 후보의 적합성, 인지도 근거, 라이선스·비용·실행 조건과 중복을 검토하고 제작 담당에게 선정 결과를 전달한다. 필요한 정보가 없으면 해당 결정만 보류한다.
6. 제작 결과의 역할 범위, 소속·보고 대상, 실제 스킬 경로, 시작 프롬프트, 사용 예시, 검증 결과를 확인한다.
7. 회장님에게 선택 이유와 완성된 결과를 보고한다. 추천, 파일 작성, 설치, 실제 실행 검증을 구분하고 실제로 위임했는지 정확히 밝힌다.

완료 기준: 요청된 탐색·제작 산출물이 연결되고, 중복과 파일 참조를 확인했으며, 결과와 실행 상태를 회장님에게 전달했다.
