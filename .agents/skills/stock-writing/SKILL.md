# 주식 블로그 집필

프로젝트의 AGENTS.md를 따른다. 편집 브리프와 근거 자료를 읽고 작성한다.

1. 독자 질문과 핵심 답을 정한다. 근거가 부족하면 먼저 필요한 자료를 표시한다.
2. 과장 없는 제목 후보 3개를 제안한다. 검색량과 검색 순위를 확인하지 않고 수치나 효과를 단정하지 않는다.
3. 기본 구성은 핵심 요약 → 기업/이슈 배경 → 주요 분석 → 위험 요인 → 다음 확인 지표 → 마무리다. 글의 목적에 맞게 줄이거나 바꾼다.
4. 수치와 중요한 사실 가까이에 출처 ID 또는 링크를 붙이고 끝에 출처 목록을 제공한다.
5. 전문 용어는 간단한 설명을 붙인다. 비교는 표를 쓰고, 인과관계는 근거가 있을 때만 단정한다.
6. 결론에서 확인된 사실, 해석, 조건부 전망이 섞이지 않도록 다듬는다.
7. 플랫폼이 지정되지 않으면 일반적인 한국어 블로그 형식으로 작성하고 플랫폼 고유 기능을 전제하지 않는다.

완료 기준: 자료에 없는 사실을 추가하지 않았고, 독자가 핵심 질문의 답과 주요 위험을 이해할 수 있다.
