# 주식 블로그 집필

프로젝트의 AGENTS.md를 따른다. 편집 브리프와 근거 자료를 읽고 작성한다.

새 원고나 기획을 바꾸는 집필 요청에는 [Notion 기획 인계 절차](../stock-editorial/references/notion-planning-handoff.md)를 적용한다. 이번 요청에서 실제 조회한 회의록 본문·출처·확정 결정을 편집장에게 받거나 직접 조회한다. 작가에게 도구가 없으면 편집장이 가져온 자료를 사용하고 조회 주체를 정확히 기록한다. 단순 오탈자·짧은 문장 편집에는 전체 조회를 강제하지 않는다.

1. 독자 질문과 핵심 답을 정한다. 근거가 부족하면 먼저 필요한 자료를 표시한다.
2. 과장 없는 제목 후보 3개를 제안한다. 검색량과 검색 순위를 확인하지 않고 수치나 효과를 단정하지 않는다.
3. 기본 구성은 핵심 요약 → 기업/이슈 배경 → 주요 분석 → 위험 요인 → 다음 확인 지표 → 마무리다. 글의 목적에 맞게 줄이거나 바꾼다.
4. 수치와 중요한 사실 가까이에 출처 ID 또는 링크를 붙이고 끝에 출처 목록을 제공한다.
5. 전문 용어는 간단한 설명을 붙인다. 비교는 표를 쓰고, 인과관계는 근거가 있을 때만 단정한다.
6. 결론에서 확인된 사실, 해석, 조건부 전망이 섞이지 않도록 다듬는다.
7. 플랫폼은 현재 프로젝트 기본값인 WordPress를 따른다. 최신 사용자 지시가 있으면 우선하고 설치된 테마·플러그인·게시 연결은 확인 전 전제하지 않는다.
8. 회의록의 확정 방향을 반영하되 제안·미정은 확정하지 않는다. 금융 수치·인용은 공식 자료로 재검증된 근거를 사용한다. 내부 회의 정보와 개인 정보를 공개 원고에 자동 포함하지 않는다.
9. 원고의 공개 출처 목록과 별도로, 참조 URL·회의일·조회일·반영 결정·미해결 사항을 편집장에게 전달한다. 접근 불가와 중요한 충돌은 영향 범위를 표시하고 나머지 작업을 진행한다.

WordPress 공개발행 자동화는 설정되지 않았다. 게시 요청이 있을 때만 승인된 목적지·저장/공개발행 범위와 실제 쓰기 권한에 맞춰 처리하고 결과를 재조회한다. 이미 승인된 동작은 재승인받지 않는다. 원고 작성, 초안 저장, 공개발행 상태를 구분해 보고한다.

완료 기준: 확인된 기획과 근거를 유지하고 내부 정보를 분리했으며, 독자가 핵심 질문의 답과 주요 위험을 이해할 수 있다. 조회·반영 기록과 남은 한계를 편집장에게 전달했다.
