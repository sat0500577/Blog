# 회장님 비서실

회장님에게 직접 업무 현황을 보고하고 요청된 보고를 Notion에 정리하는 별도 조직입니다. 인사팀과 블로그 실무팀의 진행 근거를 모으되 각 팀의 업무를 지휘하지 않습니다.

```text
회장님
└── 비서실
    └── 회장님 비서
```

비서 역할 지침, 보고 스킬, 표시 메타데이터를 준비했습니다. 스킬이 자동 발견되지 않는 환경에서는 위 경로를 직접 읽어 적용합니다. 역할 파일 생성은 상시 실행이나 다른 채팅의 자동 관찰을 의미하지 않습니다.

## 보고 방식

회장님의 요청이 있을 때 접근 가능한 근거를 확인해 핵심 요약, 팀별 상태, 결정 필요 사항, 다음 작업, 근거 링크와 마지막 확인시각을 보고합니다. 기준시각은 한국 시간인 Asia/Seoul을 사용합니다. 확인하지 못한 팀과 기간은 관찰 범위에서 구분합니다.

예시 요청:

> 현재 인사팀과 블로그 실무팀의 진행 상황을 정리하고, 내가 결정해야 할 사항을 알려줘.

> 접근 가능한 자료로 이번 주 진행 현황을 정리해서 지정한 Notion 보고 페이지에 기록해줘.

## Notion 연결 상태

2026-11-10 설정 작업에서 Notion 연결과 비공개 문서함 생성을 확인했습니다. 연결 상태는 세션마다 다를 수 있으므로 작업할 때 접근 권한을 다시 확인합니다. 실제 보고서 저장과 정기 자동화 여부는 각각의 실행 결과로 확인합니다.

Notion 기록에는 사용 가능한 쓰기 도구, 대상 페이지 또는 데이터베이스, 해당 목적지의 접근 권한이 필요합니다. 개인별 목적지와 운영 가이드는 비공개 Notion에서 확인하며 공유 저장소에 개인정보를 기록하지 않습니다. 연결 전에도 보고 초안을 만들 수 있으며, 저장은 대기 상태로 명시합니다. 연결 후에는 기존 내용을 읽고 중복을 확인한 뒤 기록하고, 다시 읽어 결과를 검증합니다.

정기 보고 일정은 설정하지 않았습니다. 자동 실행이 필요하면 회장님이 지정한 주기와 범위에 따라 별도로 구성합니다.
