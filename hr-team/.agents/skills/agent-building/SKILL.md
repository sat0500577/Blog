# 스킬 기반 에이전트 제작

[프로젝트 공통 지침](../../../../AGENTS.md)과 [에이전트 제작 담당 역할](../../../agents/agent-builder.md)을 따른다. 탐색·비교는 skill-discovery, 최종 선정과 통합 보고는 agent-skill-management가 담당한다.

1. 목표와 요구 기능, 선정 스킬의 실제 내용을 읽는다. 기능별로 어떤 스킬을 사용하는지 연결한다.
2. 소속과 보고 대상, 역할 범위, 입력, 수행 단계, 출력 형식, 완료 기준, 필요한 데이터와 도구를 명시한다.
3. 기존 에이전트 보완으로 충분한지 확인하고, 새 역할이 필요한 경우에만 역할 파일을 추가한다.
4. 시작 프롬프트와 대표 요청 예시를 작성한다. 입력이 없거나 도구에 접근하지 못하면 무엇을 요청하거나 보류할지 포함한다.
5. 설치가 배정되어 있으면 라이선스와 실행 조건을 확인하고 원본 출처·버전을 남긴다. 맞춤 지침을 보존하고 중복 정리와 참조 갱신을 함께 수행한다.
6. 파일 참조를 점검하고 대표 입력으로 가능한 동작을 검증한다. 금융 분석의 수치·시점·계산 결과를 확인하고, 데이터나 실행 도구가 없으면 검증 대기 항목으로 보고한다.
7. 팀장에게 역할 파일, 스킬 연결, 프롬프트, 사용 예시와 검증 결과를 전달한다. 파일 생성만으로 지속 실행이나 자동 등록이 완료됐다고 표현하지 않는다.

완료 기준: 요청에 맞는 역할과 프롬프트가 있고 스킬 참조가 유효하며, 준비·설치·실행 검증 상태가 구분된다.
