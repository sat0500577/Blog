# 단계별 기획 인터뷰

아래는 질문 목록을 한꺼번에 보내기 위한 체크리스트가 아니다. 이미 답한 내용을 제외하고, 선결 질문부터 한 번에 1~2개만 골라 묻는다. 다음 질문은 답을 받은 뒤 정한다.

| 확인 영역 | 회장님에게 물을 선호·결정 | 에이전트가 조사할 사실 |
|---|---|---|
| 목표·성공 기준 | 독자에게 어떤 도움을 주고 어떤 성과를 원하는가 | 이용 가능한 측정 방법과 기존 성과 자료 |
| 독자 | 초보·중급 등 누구를 위한 글인가 | 실제 독자 질문과 접근 가능한 피드백 |
| 시장·범위 | 국내·미국, 기업·산업·차트 중 어디에 집중할까 | 자료 출처, 종목 식별, 해당 시장의 데이터 조건 |
| 포맷·차별점 | 해설·분석·요약 등 어떤 글을 원하는가 | 기존 글과 비교 가능한 콘텐츠 구조 |
| 근거·운영 여력 | 직접 경험을 담을지, 주당 어느 정도 작업할 수 있는가 | 접근 가능한 공시·IR·통계와 필요한 갱신 주기 |

질문 흐름 예시: “이 블로그로 독자에게 가장 주고 싶은 도움은 무엇인가요?” → 답을 받은 후 대상 독자 확인 → 독자에 맞는 시장·콘텐츠 포맷 확인. 이미 시장이나 플랫폼을 답했다면 다시 묻지 않는다.

운영 여력을 넘는 빈도를 임의로 정하지 않는다. 선호를 잘 모르겠다는 답에는 소수의 선택지와 추천 이유를 제시한다. 조사 결과가 없으면 추정치를 사실로 채우지 않는다.

차트가 필요하면 이미지 설명·시계열 분석·지표 계산·백테스트의 차이를 짧게 설명하고 필요한 범위를 확인한다. 실적·산업 주제는 금융 참고자료를 질문 발굴에만 활용하며 그 안의 예시를 최신 사실로 사용하지 않는다.

## 주식 전문 질문의 분기

실적 중심이면 [실적 전망 참고](../../../../references/financial/earnings-preview.md), 산업·기업 비교 중심이면 [산업 개요 참고](../../../../references/financial/sector-overview.md)를 읽어 아래처럼 콘텐츠 관점을 구체화한다. 필요한 질문만 골라 한 번에 1~2개씩 묻는다.

- 실적: “독자에게 매출 성장, 이익률, 현금흐름 가운데 어떤 지표를 먼저 이해시키고 싶나요?” 선택한 지표의 실제 값과 일회성 요인·회사 가이던스는 에이전트가 공시·IR로 조사한다.
- 가치평가: “기업의 성장 이야기에 집중할까요, 비교기업과 평가 가정을 설명하는 가격 분석까지 포함할까요?” 비교 기준과 민감도는 기획서에 자료 요구사항으로 남긴다.
- 산업: “한 기업을 깊게 볼까요, 밸류체인과 경쟁사를 연결해 산업 전체를 이해시키는 연재를 만들까요?” 기업 관계·경쟁우위는 확인된 근거로 조사한다.
- 반론·갱신: “각 분석에 반대 근거와 판단을 수정해야 할 지표를 넣고, 다음 실적 발표 때 다시 점검하는 형식은 어떤가요?” 실제 발표 일정과 변경 공시는 에이전트가 확인한다.

질문의 추천 방향은 제안이며 답변 전 확정하지 않는다. 특정 기업의 현재 수치·가격 전망·자료 조사를 회장님에게 떠넘기지 않는다.

목표·독자·시장·포맷·근거 계획·운영 여력·성공 기준이 기획 가능한 수준이면 인터뷰를 끝낸다. 확정 사항, 추천 제안, 남은 미정을 요약해 확인하고 기획서 작성으로 넘어간다. 추가 질문은 결과에 중요한 영향을 주는 미정에 한정한다.
